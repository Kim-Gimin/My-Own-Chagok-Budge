# 차곡가계부 0.7.0 · 복구 소스

0.7.0 / versionCode12 / DB3. 2026-11-15 배포본을 2026-11-20에 재구성한 소스입니다. 당시 작성한 원본 소스 ZIP을 새로 찾았다는 뜻은 아닙니다.

## 기능

월 지출 예산, 저축·투자 납입 목표, 반복 예정 기록, 자주 쓰는 기록, 월별 추이·전월 비교, 계획 포함 ZIP 백업을 제공합니다. 반복 설정만으로 실제 거래가 생기지 않으며 확인 후 기록합니다. 투자와 저축은 지출 합계와 분리합니다. 저축회수·기초자산은 아직 도입 전입니다.

## 복구 근거

이전 공개 보관본 v0.6.2-lifestyle의 앱 코드에 설치 패키지에서 실제 버전을 읽는 표시 함수와 0.7.0/code12 설정을 반영했습니다. 동일한 변경을 원본 로컬 보관 소스에 적용해 빌드한 결과, 보관된 0.7.0 APK의 classes.dex와 AndroidManifest.xml·리소스·자산의 바이트가 모두 같았습니다. 서명과 ZIP 포장 전체가 동일하다는 주장은 하지 않습니다. 공개 보관본으로 다시 빌드해도 classes.dex와 매니페스트·리소스·폰트 파일이 일치하며, 두 OFL 안내 텍스트는 줄바꿈만 다릅니다. [상세 근거와 검사 결과](https://github.com/Kim-Gimin/My-Own-Chagok-Budge/blob/main/docs/releases/0.7.0.md)를 확인하세요.

공개 예시 정리 기준을 유지하며 실제 사용자 장부·과거 APK·서명키를 포함하지 않습니다. 키는 저장소 밖에서 지정하세요. 최신 앱 코드는 main이며 이 보관 브랜치를 현재 앱으로 덮어쓰지 마세요.
