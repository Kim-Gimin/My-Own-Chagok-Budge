## 발견·수정한 문제와 확인

- 끝 행 중심과 같은 좌표에서는 한 칸 앞에 멈추던 경계 판정을 보정했습니다. 높이가 다른 긴 이름 행도 맨 위·맨 아래와 인접 위치로 이동합니다.
- 끌기 중 행을 제거하지 않고 translation으로만 표시합니다. 손을 놓은 뒤 한 번 저장하며 제자리 드롭·CANCEL·대화상자 종료는 저장하지 않습니다. 설정 변경 리스너로 쓰기 횟수를 검사했습니다.
- 행 분리·대화상자 종료 시 지연 콜백·자동 스크롤·애니메이션을 취소합니다. 끌기/자리잡기 중 추가·삭제·유형 전환을 막고, 보통 상태의 삭제·복원은 유지합니다.
- 이름을 짧게 밀면 스크롤, 길게 누르면 끌기, 손잡이는 바로 끌기를 시작합니다. 양 끝 자동 스크롤과 긴 행의 이동을 실제 Android 화면 입력 경로로 검사했습니다.
- UiAutomation 접근성 트리에서 사용자 정의 위로/아래로 이동 동작을 찾아 실행했습니다. 행의 접근성 노출도 확인했습니다.
- 기존 COR1·DB5·XLSX/ZIP 형식·회계 합계·권한·외부 라이브러리는 변경하지 않았습니다. 기존 순서와 거래/계획을 업데이트 전후 비교했습니다.
- 서명 비밀번호의 스크립트 고정값을 제거하고 CHAGOK_KEYSTORE_PASSWORD 프로세스 환경변수로 전달합니다. 원본 키는 유지하며 실제 값·키·패치는 Git/Release에 포함하지 않습니다.

## 환경과 한계

JDK17, Android API36 빌드, 전용 API35 x86_64 에뮬레이터(1080×2316, 450dpi)에서 합성 자료만 사용했습니다. 밝은 모드 글꼴1.0, 어두운 모드 글꼴1.3·나눔명조에서 검사하고 화면도 확인했습니다. 실제 S23 Ultra/OneUI·Android16과 TalkBack 음성 안내를 직접 조작한 검사는 수행하지 않았습니다. 접근성 동작 검사는 실제 노드 기반 자동화 결과이며 TalkBack 수동 검사와 구분합니다. 실제 사용자 폰에 초기화 검사를 실행하지 않았습니다.
