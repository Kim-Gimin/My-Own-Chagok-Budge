## 0.8.13 상세 분류 순서

- CategoryStore가 기존 종류별 StringSet/삭제 목록에 order_유형 문자열(COR1)을 별도로 적용합니다. 저축회수는 저축을 공유하며 기본 목록은 기존 가나다순입니다. 사용자 순서 뒤에 새 참조 분류가 붙습니다.
- CategoryOrder는 순수 JVM 순서/코덱 로직입니다. 손상된 설정은 읽기에서 가나다순으로 대체하고 덮어쓰지 않습니다. move만 해당 유형의 순서 키를 저장합니다.
- MainActivity의 상세 분류 관리에 고정된 추가 버튼과 48dp ↑ ↓ 버튼을 추가했습니다. 관리 중에는 거래·계획 참조를 재사용하고 분류만 다시 그립니다.
- 현재 XLSX/ZIP은 순서 설정을 포함하지 않습니다. 전체 초기화는 category_choices 전체를 지우므로 순서도 삭제합니다. DB5·기존 장부/시각/ID/rowid·계획·생활비 선택·회계 합계를 유지합니다.
- CategoryOrderTests와 Android order/orderdark/orderreopen/orderbefore/orderupgrade를 확인합니다. 신규 권한·라이브러리는 없습니다.

## 0.8.12 시간 기록

- `Entry.time=HH:mm:ss`; 이전 생성자와 시간 없는 파일은 자정입니다. DB1~4→5는 기존 rowid/ID/거래 필드·feature_state·설정 보존 및 실패 롤백이 필수입니다.
- 새 초안은 현재 시각, 수정은 원래 시각을 유지합니다. 사진 기준 달력 다음 → 시계, 뒤로 → 달력, 최종 확인만 반영합니다. 초는 시계의 별도 버튼입니다.
- A~F 기존 엑셀 열 위치를 바꾸지 않고 G에 시간을 추가했습니다. SMV4/ZIP3이며 이전 코덱 읽기를 유지합니다. 자정 fingerprint는 기존과 같아야 합니다.
- `TimeTests`, Android `time/timebefore/timeupgrade/timedark`를 확인하세요. 실제 폰에 테스트를 실행하지 않습니다. 합계·원금 보호는 일자 기준으로 유지합니다. 새 권한·외부 라이브러리는 없습니다.
