# 사용 설명서 — 0.8.14

## 기록과 달력

처음 실행의 기본 화면과 정상 재진입은 홈입니다. 다른 시작 화면을 직접 고른 경우 새 실행은 그 설정을 따릅니다. 달력 탭은 현재 달과 오늘을 보여 줍니다. 좌우 스와이프/연월 선택으로 이동하고 날짜를 눌러 내역을 확인하세요. +는 선택 날짜의 지출 금액 입력부터 열리며 적용 후 돈의 성격·상세분류·메모를 입력합니다. 분류는 유형에 맞게 직접 추가·선택·삭제합니다.

## 자주 쓰는 상세 분류를 위로 옮기기

**설정 → 상세 분류 관리**에서 수입·지출·저축·투자를 선택하세요. **+ 상세 분류 추가**로 바로 등록하고 왼쪽 **≡ 손잡이**를 끌거나 이름을 길게 누른 채 원하는 자리로 옮깁니다. 목록 위·아래 끝으로 끌면 자동으로 스크롤됩니다. 순서는 자동 저장되어 앱을 다시 열어도 유지됩니다. 저축회수는 저축의 순서를 함께 사용합니다.

기록이나 예산·반복·즐겨찾기에서 분류를 선택할 때도 이 순서가 적용됩니다. 사용자 순서를 정한 뒤 새로 생긴 분류는 아래에 붙습니다. 삭제·복원도 같은 화면에서 할 수 있고 기존 거래와 합계는 유지됩니다. 분류 순서는 기기 내 설정으로 저장되며 현재 XLSX/ZIP 백업에는 포함하지 않습니다.

## 날짜와 시간

새 기록은 현재 시각이 자동으로 들어갑니다. 금액 입력창 위 날짜·시간을 누르면 달력이 열립니다. 날짜를 고른 뒤 **다음** → 시계에서 시·분 선택 → **확인**을 누르세요. **뒤로**는 날짜 선택으로 돌아가며 취소하면 원래 값이 유지됩니다. 초까지 바꾸려면 시계의 **초** 버튼을 누르세요. 적용 후 새 기록에서 분류·메모를 확인하고 저장합니다.

기존 기록과 시간 없는 엑셀은 모두 `00:00:00`입니다. 기록 수정 화면의 날짜 또는 시간에서도 같은 방식으로 조정합니다. 내역에는 시간이 표시되며 같은 날짜는 최근 시간부터 나옵니다. 시간은 합계나 생활비 반영 여부를 바꾸지 않습니다.

엑셀의 기존 여섯 열 뒤 **G열 시간**에 `14:05:36`처럼 입력합니다. 비우면 자정이며 금액·돈의 성격의 위치는 그대로입니다. 시간까지 복원하려면 0.8.12 이상을 사용하세요. 해지·배분 연결은 전체 ZIP으로 보관하세요.

## 월 생활비·자유금액

홈 → 예산·목표·반복 관리에서 지출 예산 금액을 정하고 상세분류를 비우면 전체 생활비 예산입니다. 반영할 상세분류만 체크해 저장하세요. 출장비를 해제해도 전체 지출에는 남습니다. 선택은 모든 월에 공통이고, 금액은 특정 월/매월 기본값을 정합니다.

예: 예산100만원, 포함 지출35만원, 제외 출장비30만원이면 전체 지출65만원, 생활비 사용35만원, 잔액65만원입니다. 아직 선택한 적이 없으면 전체 지출을 반영하고, 전체 해제를 저장하면0개를 반영합니다. 선택 저장 후 새 분류는 직접 체크하세요. 달력의 생활비 보기도 같은 선택을 사용합니다.

## 수입·저축·투자·회수

엑셀과 앱 금액은 양수로 입력합니다. 수입/지출/저축/투자/저축회수를 구분하세요. 이전 원금은 기초자산에, 올해 실제 납입은 저축에 기록합니다. 이미 기록한 돈을 기초자산과 수입/저축 양쪽에 다시 넣지 않습니다.

적금 만기는 ‘저축 해지·배분’에 원금·실수령·이자/기여금·재가입·투자 금액을 입력합니다. 원금은 회수, 이자·기여금은 수입, 새 예금은 저축, 주식은 투자로 처리합니다. 자동 생성된 내역을 엑셀에 다시 수동 입력하지 마세요. 남은 현금을 실제로 썼으면 해당 소비만 별도 지출입니다. 상세 예시는 앱 설정 → 설명서 보기에 있습니다.

## 검색·통계·결산

내역의 돋보기는 메모 검색, A–Z는 상세분류 선택·정렬입니다. 통계는 월/연/올해1월1일부터 오늘/지정 기간을 고릅니다. 원형 차트를 돌리거나 항목을 눌러 상세 내역을 확인합니다. 결산은 연간·종합·기간별로 볼 수 있습니다. 달력 탐색 월은 통계 기간과 별개입니다.

## 반복·예산·백업

예산·목표/반복·자주 쓰는 기록에서 돈의 성격에 맞는 상세분류를 선택합니다. 다른 성격으로 바꾸면 분류를 다시 선택하며 저축↔회수는 같은 목록입니다. 계획 설정 금액 자체는 실제 거래가 아닙니다.

다른 기기로 옮길 때는0.8.11의 전체 XLSX 또는 ZIP을 사용하세요. 전체 XLSX에는 계획 시트도 있지만 해지·배분 연결까지 유지하려면 ZIP이 필요합니다. 옛 앱에서는 새 계획 시트를 복원하지 않습니다. 가져오기는 현재 자료에 추가하고 같은 계획은 현재 값을 우선합니다.

## 설정과 종료

다크 모드·글꼴·홈 표시·시작 화면·PIN을 설정할 수 있습니다. 설정 뒤로는 홈, 설명서 뒤로는 설정입니다. 홈의 첫 뒤로는 종료 안내이고 한 번 더 누르거나 앱 종료 버튼을 누르면 종료합니다. 앱 전체 초기화는 장부·분류·화면·잠금 설정까지 삭제하므로 필요한 백업을 앱 밖에 먼저 저장하세요.
