## 최근 버전의 변경 내용

### 1.0.0 — 하단 메뉴 편집

설정·메뉴의 ‘하단 메뉴 편집’(또는 하단 메뉴 길게 누르기)에서 메뉴의 기능 10개 중 3~6개를 골라 하단에 놓고 끌어서 순서를 바꿉니다. 예산·목표·반복, 월별 추이, 기초자산, 저축 해지·배분도 넣을 수 있습니다. 저장해야 적용되고 취소하면 그대로이며, 기본 배치로 기존 6개를 되돌립니다. 업데이트 직후 배치는 0.9.2와 같습니다. [1.0.0 상세 안내](releases/1.0.0.md).

### 0.9.2 — 다른 앱 복귀 시 보던 화면 유지

카드 내역 확인 등으로 다른 앱에 잠시 갔다 돌아오면 보던 화면·달·필터·스크롤과 살아 있는 입력창을 유지합니다. PIN 확인 뒤에도 작업을 이어가고 저장된 화면 상태가 있으면 Activity 재생성 시 복원합니다. 완전 종료 후 새 실행은 기본 홈이며 사용자 시작 화면 설정을 우선합니다. 프로세스 종료 뒤 저장하지 않은 대화상자 초안을 복원하는 기능은 아닙니다. [0.9.2 상세 안내](releases/0.9.2.md).

### 0.9.1 — 예산 기준·전체 지출 동시 비교

월별 추이·전월 비교 화면에 두 그래프를 함께 표시합니다.

- **예산 기준 지출:** 적용 중인 전체/분류별 예산을 선택해 해당 분류의 지출을 전월 같은 기간·예산 속도선과 비교합니다. 전체 예산만 생활비 반영 분류를 따르며, 분류별 예산은 해당 분류만 집계합니다. 예산 초과·잔액도 표시합니다.
- **전체 지출 비교:** 예산 포함 여부와 관계없이 모든 지출을 전월 같은 기간과 비교합니다.

현재 월은 두 그래프 모두 오늘까지 계산합니다. 생활비 반영 분류가0개여도 전체 지출 그래프는 유지하며, 예산이 없으면 예산 설정 안내와 전체 지출을 표시합니다. [0.9.1 상세 안내](releases/0.9.1.md).

### 0.9.0 — 누적 지출 속도

선택한 달의 누적 지출, 전월 같은 기간 비교, 예산 권장 속도선과 초과·잔액 안내를 추가했습니다. 0.9.1에서 예산 기준과 전체 지출을 함께 보는 방식으로 확장했습니다. [0.9.0 상세 안내](releases/0.9.0.md).

### 0.8.14 — 상세 분류 끌어서 정렬

상세 분류 관리에서 손잡이를 끌거나 이름을 길게 눌러 순서를 바꿉니다. 끝 위치 자동 스크롤, 취소 시 미저장, 접근성 위/아래 이동을 지원합니다. [0.8.14 상세 안내](releases/0.8.14.md).

### 0.8.13 — 상세 분류 추가·순서

보관 APK와 앞뒤 소스를 대조해 [복구 소스·ZIP·검증 결과](releases/0.8.0.md)를 추가했습니다. DEX 함수 실행 코드 비교 범위와 메타데이터 차이를 기록했습니다. 보관0.8.0 APK에도 연결 거래의 이동 전체 수정 코드가 있어 이를0.8.1 최초 도입으로 단정하던 설명을 정정했습니다.

### 0.7.0 복구·0.8.1 설명 보강 — 2026-11-20

- **0.7.0:** 이전 보관 소스에서 재구성해 APK와 대조한 [복구 소스](releases/0.7.0.md)를 추가했습니다. 생활관리 확장과 실제 설치 버전 표시를 포함합니다.

### 과거 릴리스 등록 — 2026-11-22 당시 기록

과거 소스 보관 릴리스28개를 추가해 **당시 총31개, 최신0.8.13**이었습니다. 이 수치는 그날 작업 결과입니다. 이후0.8.14·0.9.0·0.9.1·0.9.2가 추가되어 **현재는 총35개, 최신0.9.2**입니다. [당시 등록 검증](RELEASE_HISTORY_VALIDATION.md)을 참조하세요.

0.8.10 이전 릴리스는 소스 보관용이며 GitHub Source code ZIP/tar.gz와 변경 내용을 제공합니다. 설치용 APK는0.8.11 이후 공개 배포물에서 받을 수 있습니다. 0.6.2 변형판은 설치 앱의 versionName/code가 같아도 보관 이름으로 구분합니다. 실제 사례가 포함된 과거 원본 APK·엑셀, 개인 장부·백업·서명키는 공개하지 않습니다.
