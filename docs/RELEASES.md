**0.1.0부터 0.9.1까지 34개 버전·보관판을 [릴리스 목록](https://github.com/Kim-Gimin/My-Own-Chagok-Budge/releases)에서 볼 수 있습니다.** 2026-11-22에 과거 소스 보관 릴리스28개를 추가했습니다. 0.6.2의 변형판은 설치 앱의 versionName/code가 같아도 별도 보관 이름으로 구분합니다.

0.7.0과 0.8.0은 보관 APK와 대조한 복구 소스이며 각각 새 v0.7.0/v0.8.0 태그를 기존 복구 브랜치와 같은 커밋에 연결했습니다. 원래 소스 ZIP을 새로 발견했다는 뜻은 아닙니다. 기존 태그·소스·0.8.11~0.8.13 릴리스와 첨부 파일은 유지했습니다.

0.8.10 이전 릴리스는 **소스 보관용**으로 Source code ZIP/tar.gz와 변경 내용을 제공합니다. 실제 사례가 포함된 원본 과거 APK·엑셀과 개인 장부·백업·서명키는 첨부하지 않습니다. 설치용 APK는0.8.11 이후 공개 배포물에서 받으세요. 2026-11-22 목록 정리 당시에는 최신0.8.13을 유지했습니다. 현재 최신 설치 버전은 아래 APK 항목을 확인하세요. [등록 검증](RELEASE_HISTORY_VALIDATION.md)을 함께 확인하세요.

## 0.7.0·0.8.1 보강 — 2026-11-20

- **0.7.0:** 원래 소스 ZIP 미발견 기록을 유지하되, 이전 보관 소스에서 재구성해 보관 APK와 대조 검증한 [복구 소스](releases/0.7.0.md)를 추가했습니다. 새로 찾은 원본 개발 커밋으로 가장하지 않습니다. 복구 소스에는 생활관리 기능과 실제 설치 버전 표시 개선이 반영돼 있습니다.
- **0.8.1:** 기존 `v0.8.1` 태그의 [전체 소스·ZIP·기능 설명](releases/0.8.1.md)을 명확히 연결했습니다. 저축회수 직접 입력은 0.8.2 변경과 구분합니다.
- 이번 변경은 과거 소스와 설명의 보강입니다. 최신 앱 버전·DB·사용자 데이터는 바꾸지 않았으며 원본 과거 APK·개인 자료·키는 공개하지 않습니다.

## 0.8.0 보강 — 2026-11-20

0.8.0도 보관 APK와 앞뒤 소스를 대조해 [복구 소스·ZIP·검증 결과](releases/0.8.0.md)를 추가했습니다. 원본 소스 ZIP을 발견한 것은 아니며 DEX 함수 실행 코드 비교의 범위와 메타데이터 차이를 명시합니다. 실제0.8.0 APK에 연결 거래의 이동 전체 수정 분기가 이미 있는 것도 확인해0.8.1 설명에 반영했습니다. 최신 앱·DB·사용자 데이터는 변경하지 않습니다.
