## 보존과 예시

- 가상 예시의 원금1,000만원, 이전 원금650만원, 수령1,020만원, 이자12만원/기여금8만원, 예금800만원/투자150만원, 잔액70만원을 실제 입력·미리보기·복원 검사로 확인했습니다. 화면도 직접 확인했습니다.
- 새 빈 양식은 정리된 앱 XlsxIO로 생성하고 예시 시트까지 검사했습니다. 사용자 원본 엑셀을 수정해 만든 파일이 아닙니다.
- 업데이트 전후 합성 fixture의 거래 내용/ID/rowid·기초자산·이동·계획·분류·설정 스냅샷을 비교했습니다. DB4와 기존 인증서를 유지합니다.
- 최종5개 Android 검사 APK의 모든 ZIP 엔트리가 배포 APK와 같습니다. 설치된 APK SHA256도 배포 파일과 같고 기존 v2/v3 서명 인증서를 검증했습니다.

## 공개 이력

과거 소스 태그26개도 가상 예시로 정리했습니다. 실제 사례가 포함된 과거 문서·APK·양식·충돌 사본은 공개 Git 트리에서 제외했습니다. 정리한0.8.1~0.8.10의 JVM 검사를 각각 실행했습니다. 원본 개발 커밋으로 가장하지 않으며 원래 배포일과 이관 날짜를 구분합니다.

전체 공개 참조와 현재 파일의 텍스트·XLSX 내부 XML에서 실제 사례와 인증 자료를 검사했습니다. 키·개인 장부·원본 백업·빌드 도구는 포함하지 않습니다. APK는 Git에 넣지 않고 안전한 새 Release만 제공합니다.

이전 SHA의 GitHub 캐시/외부 복제본은 브랜치·태그 정리와 별개입니다. [GitHub 공식 절차](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)를 따르며, 캐시 삭제가 완료됐다고 주장하지 않습니다. 이전 클론의 재푸시는 차단하고 새 클론을 OneDrive 밖에서 사용합니다.
