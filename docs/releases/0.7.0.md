## 이 버전의 내용

앞서 0.6.2 생활관리 확장판으로 작업한 기능을 별도 배포 번호 0.7.0으로 구분했습니다.

- 월 지출 예산: 선택 월과 매월 기본 예산, 분류별 예산과 사용액·잔액 표시.
- 저축·투자 납입 목표: 실제 납입액과 목표 진행률 확인.
- 반복 기록: 주·월·연 예정일, 확인 후 실제 거래 저장, 일시 중지·재개·건너뛰기. 반복 설정만으로 거래 합계가 늘어나지 않습니다.
- 자주 쓰는 기록: 금액·돈의 성격·분류·메모를 저장한 틀로 새 기록 입력.
- 월별 추이·전월 비교: 기간별 수입·지출·저축·투자 흐름 비교.
- 계획 포함 ZIP: 거래와 예산·목표·반복·즐겨찾기 설정을 함께 보관. 같은 계획 키/ID는 현재 설정 우선.
- 버전 표시: 설정·엑셀 화면·의견 공유에서 설치 패키지의 실제 버전을 읽도록 개선.

## 다음 버전과의 구분

0.7.0의 엑셀 백업에는 계좌를 포함한 7열 형식이 사용됩니다. 날짜/내역/상세 분류/**금액/돈의 성격**/고유ID의 6열 및 새 양식의 양수 입력·참고 예시는 **0.7.1** 변경입니다. 저축회수·만기 배분(DB4)은 **0.8.0 이후**, 기초자산은 **0.8.3 이후**입니다. 최신 앱의 동작을 이 버전의 기능으로 소급하지 않습니다.

## 소스 복구 근거

처음 이관할 때 0.7.0 번호의 원본 소스 ZIP을 찾지 못해 APK만 보관된 것으로 기록했습니다. 2026-11-20에 이전 보관본과 APK를 대조해 아래 변경으로 배포 코드를 재현했습니다.

1. 이전 생활관리 보관본의 `app/build.gradle`을 0.7.0/code12로 설정.
2. `MainActivity`에 `appVersion()`을 추가하고 설정·엑셀 화면·의견 공유의 고정 버전 문자열을 실제 설치 버전 조회로 변경.
3. 같은 도구 계열(JDK17, Android API36, Build Tools36)로 빌드한 뒤 보관 APK와 ZIP 내부 파일을 비교.

원본 로컬 보관본에서 재구성한 검증 빌드는 서명 메타데이터를 제외한 **13개 파일이 모두 바이트 일치**했습니다. 공개 보관본 기반 복구 소스도 `classes.dex`, 매니페스트, 리소스, TTF 폰트가 일치했고, 두 OFL 안내 텍스트는 공개 이관 때 정리된 줄바꿈만 다릅니다.

`classes.dex` SHA256:

```text
fcf023039f8409f7886eb371b8de0fedc581c0aa7a6c5c56b481108aa5b71a07
```

이는 **보관 APK와 비교해 검증한 복구 소스**입니다. 당시 작성한 원본 ZIP이나 원래 개발 커밋을 새로 찾았다는 뜻은 아닙니다. 커밋 날짜는 복구일이며 원래 배포일과 구분합니다. 서명 블록·ZIP 타임스탬프까지 포함한 APK 전체 동일성을 주장하지 않습니다.

## 이번 검증

2026-11-20 공개 복구 소스에서 JVM **598개**(Core460 + Planning138)가 통과했고 APK 빌드와 서명 검증도 통과했습니다. 기존 배포 APK의 프로그램 코드·리소스 비교를 수행했습니다. 이번 작업에서 Android UI/실기기 검사는 별도로 실행하지 않았습니다.

원본 APK·장부·서명키는 공개하지 않습니다. 복구 소스는 최신 `main`과 별도로 보관하며 현재 앱 버전이나 사용자 데이터는 변경하지 않습니다.
