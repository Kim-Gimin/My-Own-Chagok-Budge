# 0.9.2 — 다른 앱에서 돌아오면 보던 화면 유지

2026-11-24 / versionCode31 / DB5 / 패키지 `kr.chagok.ledger`.

카드 내역을 확인하려고 다른 앱으로 잠시 이동한 경우에도 홈으로 돌아가던 문제를 수정했습니다.

- **잠시 다른 앱으로 이동 후 복귀:** 보던 화면·선택한 달·필터·스크롤을 유지합니다. 같은 Activity가 살아 있으면 입력 중인 금액·메모 창도 그대로 둡니다.
- **PIN 사용:** 기존처럼 잠금을 확인하고 보던 화면으로 돌아갑니다. 자료 변경으로 필요한 갱신과 대기 중인 가져오기 처리는 이어갑니다.
- **완전 종료 후 새 실행:** 기본 홈을 표시합니다. 사용자가 정한 다른 시작 화면은 우선합니다.
- **Activity 재생성:** 저장된 화면·달·내역 표시 개수·스크롤을 복원합니다. Android가 프로세스를 종료한 뒤 저장하지 않은 입력창까지 복원하는 기능은 아닙니다.

DB5·거래/계획·백업 형식은 그대로이며, 빈 양식 내용도0.9.1과 같습니다. 새 권한·라이브러리는 없습니다. 기존 서명 인증서가 같은 APK로 빌드했습니다. 앱을 삭제하지 않고 설치해 업데이트하세요.

JVM1,484개·APK 빌드·서명 검증 통과. Android 회귀 검사 소스는 컴파일했으며 기기/에뮬레이터가 없어 실제 실행은 미실시했습니다. [변경 파일·검증과 한계](../BACKGROUND_RESUME_VALIDATION.md).
