# 0.9.0 — 지출 속도와 예산 비교

2026-11-23 / versionCode29 / DB5 / 패키지 `kr.chagok.ledger`.

**월별 추이·전월 비교** 화면에 지출 속도 분석을 추가했습니다.

1. 선택한 달의 누적 지출과 전월 같은 기간의 누적 지출을 선 그래프로 비교합니다.
2. 현재 월은 오늘까지의 기록만 계산해 진행 중인 달도 공정하게 비교합니다.
3. 전체 지출 예산이 설정되어 있으면 일별 권장 지출 속도선과 오늘까지 권장 지출 금액을 표시합니다.
4. 예산보다 더 쓴 금액 또는 예산까지 남은 금액을 문장으로 안내합니다.
5. 생활비 반영 분류를 설정한 전체 예산은 기존 생활비 선택 규칙을 그대로 따릅니다.

거래·시간·DB5·예산·생활비 선택·XLSX/ZIP 백업 형식은 변경하지 않았습니다. 새 권한과 외부 라이브러리는 없습니다.
