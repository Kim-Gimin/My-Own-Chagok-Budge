# 0.8.13 — 상세 분류 추가·순서 변경

2026-11-21 / versionCode27 / DB5 / 패키지 `kr.chagok.ledger`.

**설정 → 상세 분류 관리**를 여세요.

1. 수입·지출·저축·투자 중 원하는 유형을 고릅니다.
2. **+ 상세 분류 추가**로 새 이름을 등록합니다.
3. 이름 옆 **↑ / ↓**로 한 칸씩 옮깁니다. 맨 위의 ↑와 맨 아래의 ↓는 비활성화됩니다.
4. 순서는 자동 저장되어 앱을 종료하고 다시 켜도 유지됩니다. 기록·예산·목표·반복·즐겨찾기·생활비에서 유형별 분류를 고를 때도 적용됩니다.

저축회수는 저축 순서를 공유합니다. 사용자 순서를 정한 뒤 새 분류를 추가하면 끝에 붙고, 삭제·복원도 같은 화면에서 할 수 있습니다. 내역 A–Z 필터와 통계 금액 정렬은 기존 방식을 유지합니다.

분류 순서는 별도 로컬 설정으로 저장합니다. 기존 거래·시각·ID/rowid·계획·생활비 포함 여부·합계는 바꾸지 않습니다. DB5와 XLSX/ZIP 형식도 유지합니다. 현재 XLSX/ZIP에는 순서 설정을 포함하지 않으며, 앱 전체 초기화는 순서도 지웁니다. 빈 엑셀 양식의 내용은 0.8.12와 같습니다.

기존 원본 키로 서명했으므로 앱을 삭제하지 말고 새 APK로 업데이트하세요. [APK·빈 양식·SHA256](https://github.com/Kim-Gimin/My-Own-Chagok-Budge/releases/tag/v0.8.13) · [소스 태그](https://github.com/Kim-Gimin/My-Own-Chagok-Budge/tree/v0.8.13) · [검증 결과](../CATEGORY_ORDER_VALIDATION.md).

새 권한과 외부 라이브러리는 추가하지 않았습니다. 실제 장부·개인 백업·서명키는 공개하지 않습니다.
