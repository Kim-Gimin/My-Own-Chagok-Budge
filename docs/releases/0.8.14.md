# 0.8.14 — 상세 분류 끌어서 정렬

2026-11-23 / versionCode28 / DB5 / 패키지 `kr.chagok.ledger`.

**설정 → 상세 분류 관리**에서 순서를 바꾸는 방식이 바뀌었습니다.

1. 행 왼쪽 **≡ 손잡이**를 누른 채 위아래로 끌면 바로 움직입니다.
2. 이름 부분은 **길게 누르면**(진동) 끌 수 있습니다. 짧게 끌면 평소처럼 목록이 스크롤됩니다.
3. 끄는 동안 다른 분류가 비켜나고, 목록 위·아래 끝으로 가면 자동으로 스크롤됩니다.
4. 손을 떼면 그 자리로 저장됩니다. 기록·예산·목표·반복·즐겨찾기·생활비 선택 목록에 같은 순서가 쓰입니다.

TalkBack 사용 시에는 행의 동작 메뉴에서 **위로 이동 / 아래로 이동**을 고릅니다.

순서 설정 형식(order_유형)과 DB5, XLSX/ZIP, 거래·계획 데이터는 그대로입니다. 0.8.13에서 정한 순서도 그대로 이어집니다. 새 권한과 외부 라이브러리는 없습니다.
