# 0.9.1 — 예산 기준·전체 지출 동시 비교

2026-11-23 / versionCode30 / DB5 / 패키지 `kr.chagok.ledger`.

월별 추이·전월 비교 화면에 두 그래프를 함께 표시합니다.

1. **예산 기준 지출:** 적용 중인 전체/분류별 지출 예산을 선택합니다. 전체 예산은 생활비 반영 분류, 개별 예산은 해당 분류만 집계해 전월 같은 기간·예산 속도선과 비교하고 초과/잔액을 표시합니다.
2. **전체 지출 비교:** 예산 포함 여부와 관계없이 모든 지출을 전월 같은 기간과 비교합니다.

현재 월은 둘 다 오늘까지 계산합니다. 예산이 없으면 설정 안내와 전체 지출을 보여 줍니다. 생활비 반영 분류가 0개면 예산 기준 지출만 0원이고 전체 지출은 유지합니다. 예산을 골라도 계획과 거래 데이터는 바뀌지 않습니다.

원본 서명으로 빌드해 기존 인증서와 일치함을 확인했습니다. 앱을 삭제하지 않고 APK를 설치해 업데이트하세요. DB5·백업 형식·입력 양식 내용은 유지하며 새 권한·라이브러리는 없습니다.

JVM 1,484개와 APK 빌드·서명 검증 통과. 실제 기기·에뮬레이터 화면 실행은 미실시했습니다. [검증과 변경 파일](../DUAL_SPENDING_VALIDATION.md).
