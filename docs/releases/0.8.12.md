# 0.8.12 — 날짜·시간 기록

2026-11-20 / versionCode26 / DB5 / 패키지 `kr.chagok.ledger`.

## 사용하는 방법

1. **+ → 지출 금액 입력**을 엽니다. 새 기록에는 현재 시각이 자동으로 들어갑니다.
2. 위쪽 날짜·시간을 누르면 달력이 열립니다. 날짜를 고르고 **다음**을 누릅니다.
3. 시계에서 시·분을 고르고 **확인**합니다. **뒤로**는 달력으로 돌아갑니다. 초는 **초** 버튼에서 고릅니다.
4. **적용 → 새 기록 → 상세 분류·메모 → 저장**합니다. 취소하면 원래 날짜·시간이 유지됩니다.

내역에서 시각을 볼 수 있고 같은 날은 최근 시각부터 표시합니다. 수정 화면의 날짜·시간에서도 바꿀 수 있습니다. 복사·즐겨찾기·반복 기록을 실제 입력할 때는 새 입력 시각을 사용합니다.

## 기존 데이터와 엑셀

- 기존 거래는 **00:00:00**으로 이관합니다. 거래 내용·ID/rowid·기초자산·해지 연결·계획·설정을 보존합니다. 합계·생활비·원금 보호는 기존 일자 기준을 유지합니다.
- 엑셀 A~F 열은 그대로이며 **G열 시간**을 추가했습니다. `14:05:36` 또는 엑셀 시간 값으로 입력하고, 비우면 자정입니다. 시간 없는 이전 파일도 읽습니다.
- 시간은 전체/월별 XLSX와 ZIP에 보관합니다. 해지·배분의 연결 정보는 ZIP을 사용합니다. 시간 포함 자료는 **0.8.12 이상**에서 복원하세요. 이전 앱은 시간을 무시할 수 있습니다.
- DB1~4 → DB5 이관은 트랜잭션 안에서 실행하고 실패 시 되돌립니다. 업데이트 후 구버전 APK로의 다운그레이드는 지원하지 않습니다.

## 설치와 배포

앱을 지우지 말고 기존 원본 키로 서명한 새 APK를 설치해 업데이트하세요. APK·SHA256·빈 양식은 [v0.8.12 Release](https://github.com/Kim-Gimin/My-Own-Chagok-Budge/releases/tag/v0.8.12), 코드는 [v0.8.12 태그](https://github.com/Kim-Gimin/My-Own-Chagok-Budge/tree/v0.8.12)에 있습니다. APK는 Git 소스 이력에 넣지 않고 Release에 첨부합니다.

새 권한과 외부 라이브러리는 추가하지 않았습니다. 공개 예시·검사는 합성 자료이며 실제 장부·개인 백업·서명키는 배포하지 않습니다. [검증 결과](../TIME_VALIDATION.md)를 함께 확인하세요.
