# 1.0.0 — 하단 메뉴 편집

2026-11-24 / versionCode32 / DB5 / 패키지 `kr.chagok.ledger`.

자주 쓰는 기능을 하단 메뉴에 직접 놓을 수 있습니다.

- **여는 곳:** 설정 → 하단 메뉴 편집, 왼쪽 위 메뉴 → 하단 메뉴 편집, 또는 하단 메뉴를 길게 누르기.
- **고르기:** 결산·통계·홈·달력·내역·엑셀, 예산·목표·반복, 월별 추이·전월 비교, 기초자산·현재 보유, 저축 해지·배분 중 3~6개를 추가/빼기로 고릅니다. 위쪽 미리보기로 하단 모양을 확인합니다.
- **순서:** 왼쪽 ≡ 손잡이를 끌거나 이름을 길게 눌러 옮깁니다. TalkBack은 앞으로/뒤로 이동 동작을 씁니다.
- **저장·취소:** ‘저장’을 눌러야 적용됩니다. ‘취소’하면 바뀌지 않고, ‘기본 배치’는 처음 6개로 되돌립니다(저장해야 적용).
- 업데이트 직후에는 기존 하단 6개가 그대로입니다. 하단에서 뺀 기능도 메뉴에서 열 수 있습니다.

DB5·거래/계획·백업 형식은 그대로이며 하단 메뉴는 기기 내 설정입니다(백업 미포함). 빈 양식 내용은 0.9.2와 같습니다. 새 권한·라이브러리는 없습니다. 기존 서명 인증서와 같은 APK를 앱 삭제 없이 설치하세요.
