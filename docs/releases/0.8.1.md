## 0.8.1에서 바뀐 동작

저축 해지·배분으로 생성된 이자·재가입·투자 등의 연결 내역을 누르면, 해당 거래 하나만 고치는 대신 **그 거래가 속한 저축 이동 전체 수정 화면**을 엽니다.

예를 들어 적금을 해지해 예금과 투자로 나눠 저장한 뒤 그중 예금 내역을 누르면, 해지 원금·수령액·예금/투자 배분액을 함께 확인하고 이동 단위로 수정합니다. 생성된 한 줄만 수정해 다른 연결 내역과 어긋나는 일을 방지하기 위한 변경입니다.

확인 위치: [`MainActivity.edit()`](https://github.com/Kim-Gimin/My-Own-Chagok-Budge/blob/v0.8.1/app/src/main/java/kr/chagok/ledger/MainActivity.java). `move:`로 시작하는 거래 ID의 이동을 찾으면 `movementEditor(movement)`로 이동합니다. 실제 저장은 기존 이동 단위 저장 흐름을 사용합니다.

## 앞뒤 버전과의 구분

- **0.8.0:** DB4, 저축회수 처리, 만기 재배분, 순저축 집계가 먼저 도입돼 있었습니다.
- **0.8.1:** 그 연결 내역에서 이동 전체 수정으로 여는 동작을 개선했습니다. 수입·지출·저축·투자의 네 통계 그룹을 유지합니다.
- **0.8.2:** 일반 새 기록/수정 화면에 사용자가 직접 고르는 **저축회수** 선택지를 추가했습니다. 0.8.1의 도입 기능으로 잘못 기록하지 않습니다.
- **0.8.3:** 기초자산과 실제 원금 회수·재가입·기여금 분리 등은 이후 변경입니다.

## 소스 보관과 이번 확인

0.8.1 소스는 저축회수 직접 입력 작업 전의 보관 ZIP에서 확인해 이미 `v0.8.1` 태그로 이관돼 있었습니다. 이번에는 태그를 새로 만들거나 기존 태그를 바꾸지 않고 전체 소스·ZIP 링크와 기능 설명을 보강했습니다.

공개 소스의 앱 버전 0.8.1/code15와 DB4, 연결 거래의 편집 분기를 다시 확인했습니다. 2026-11-20 JVM **821개**(Core526 + Planning138 + Maturity157)가 통과했고 APK 빌드·서명 검증도 통과했습니다. 이번 Android UI/실기기 검사는 별도로 실행하지 않았습니다.

공개 태그의 예시는 기존 공개 자료 정리 기준을 따릅니다. 개인 사례 정리 등이 반영돼 있어 원본 APK와 전체 바이트가 같다는 의미는 아닙니다. 원본 문서·APK·장부·키를 다시 공개하지 않습니다.
